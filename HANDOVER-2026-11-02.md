## Attack bug and saved experiment

`UnitsManager_PursueEnemy` cancels executing computer attacks outside weapon range.
Jev offers attacks within range plus movement but immediately enters that firing
state, which can repeat the same attack without moving. The real-engine check
reproduced this failure before any change.

The candidate requests `ORDER_STATE_MOVE_INIT` for an out-of-range target, preserving
the firing state for targets already in range. Nine engine checks passed. Repeated
attack-failure findings fell overall, but game outcomes did not improve enough
to promote it. The source and default binary have been restored to the control's
attack behavior; the candidate patch and reproducer remain available.

Test it without changing production source:

```sh
python3 test/run-production-preview-checks.py --suite jev-attack --attack-candidate
```

The test runner copies sources and exposes controller internals only in generated
test headers. Omitting `--attack-candidate` deliberately reproduces the known
failure against the default implementation; it is not a normal passing gate.
